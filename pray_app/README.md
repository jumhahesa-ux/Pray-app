# نوێژ (Pray App)

ئەپێکی فلاتەر بۆ فێربوونی نوێژ بەپێی مەزهەبی شافیعی، لەگەڵ کاتی بانگ، قیبلەنما، قورئان، تەفسیر، تەجوید، فەرموودەی ڕۆژانە، زیکر، و ناوەکانی خودا.

## زمانەکان

ئەپەکە پشتگیری چەند زمانێک دەکات: **کوردی (سەرەکی/بنەڕەتی)**، عەرەبی، ئینگلیزی، تورکی، فارسی. بەکارهێنەر دەتوانێت لە دوگمەی 🌐 لە سەرووی سەرەکی لاپەڕەوە زمان بگۆڕێت؛ هەڵبژاردنەکە پاشەکەوت دەکرێت بۆ جاری داهاتوو. دەقی ڕووکار (ناونیشانەکان، دوگمەکان) وەرگێڕدراوە؛ دەقی قورئان و فەرموودە بە عەرەبی لەگەڵ وەرگێڕانی کوردی هاتووە (دەتوانرێت لە داهاتوودا زیاتر زمان بۆ ناوەڕۆکی دەقەکان زیاد بکرێت). فایلی `lib/l10n/strings.dart` شوێنی هەموو وەرگێڕانەکانە.

## چۆنیەتی ڕاخستن

1. Flutter SDK دابمەزرێنە: https://docs.flutter.dev/get-started/install
2. لە فۆڵدەری پڕۆژەکەدا:
   ```
   flutter pub get
   flutter run
   ```
3. بۆ دروستکردنی APK:
   ```
   flutter build apk --release
   ```
   فایلەکە لێرە دەرئەکەوێت: `build/app/outputs/flutter-apk/app-release.apk`

## ڕێگەپێدانەکانی ئەندرۆید (پێویستە)

لە فایلی `android/app/src/main/AndroidManifest.xml` ئەم دوو ڕێگەپێدانە زیاد بکە پێش `<application>`:

```xml
<uses-permission android:name="android.permission.ACCESS_FINE_LOCATION"/>
<uses-permission android:name="android.permission.ACCESS_COARSE_LOCATION"/>
```

بەبێ ئەمانە، بەشی «کاتی بانگ» و «قیبلەنما» کار ناکەن (پێویستیان بە شوێنی مۆبایلە).

## پێکهاتەی پڕۆژە

```
lib/
  main.dart              - دەستپێکی ئەپ
  theme/app_theme.dart   - ڕەنگ و فۆنت (سەوزی ئیسلامی + زێڕی)
  data/                  - هەموو زانیارییە ئیسلامییەکان (offline، بێ پێویستی بە ئینتەرنێت)
    salah_steps.dart      - هەنگاوەکانی وضوو و نوێژ (شافیعی)
    prayer_times_calc.dart- ژمێریاری کاتی بانگ بە فۆرمولی ئەستەرناسی
    hadiths.dart           - فەرموودەی ڕۆژانە
    adhkar.dart             - زیکرەکان
    asma_ul_husna.dart      - ٩٩ ناوی خودا
    tajweed_letters.dart    - مەخارج و یاساکانی تەجوید
    quran_surahs.dart       - لیستی ١١٤ سورەت + دەقی فاتیحا
  screens/                - هەموو پەیجەکان
```

## چی زیاد بکەیت لە داهاتوودا

- **دەقی تەواوی قورئان + دەنگ**: بەکارهێنانی API‌ی وەک alquran.cloud یان پاکێجی `quran` بۆ فلاتەر، یاخود دابەزاندنی JSON‌ی قورئان و خستنی وەک asset لە ناو ئەپەکەدا (کار دەکات بەبێ ئینتەرنێت).
- **تەفسیری تەواو**: هەمان شێواز، دەقی تەفسیر وەک asset یان API زیاد بکە.
- **ئاگادارکردنەوەی کاتی بانگ (notification)**: پاکێجی `flutter_local_notifications`.
- **پاشەکەوتکردنی ژمارەی زیکر**: پاکێجی `shared_preferences` ئێستا لە pubspec‌دا هەیە، تەنها پێویستە لە `adhkar_screen.dart` بەکاربهێنرێت بۆ هەڵگرتنی دۆخی ژماردن دوای داخستنی ئەپ.
- **وێنە/ئایکۆنی ئەپ**: پاکێجی `flutter_launcher_icons` بۆ داڕشتنی ئایکۆنی تایبەت.

هەموو زانیارییە ئایینییەکان (وضوو، نوێژ، ناوەکانی خودا، مەخارج) لەسەر بنەمای زانیاری گشتی و بەناوبانگی مەزهەبی شافیعی نووسراون؛ باشترە پێش بڵاوکردنەوەی گشتی، لەگەڵ مامۆستایەکی دین پشتڕاست بکرێنەوە.
